## Separação do GKR
Este projeto possui governança, versionamento, documentação e publicação próprios. O [Guivos Knowledge Repository](https://github.com/guivos-repositorio/Guivos-Knowledge-Repository) permanece como repositório institucional do ecossistema. Referências cruzadas não significam dependência de publicação nem sincronização automática.

## Publicação
O arquivo `index.html` na raiz permite a publicação por GitHub Pages a partir de `main / (root)`. A ativação deve ocorrer em **Settings → Pages**.

## Princípios
- Evidências antes de interpretações; hipóteses identificadas como hipóteses.
- Não realizar diagnósticos psicológicos automatizados.
- A Pessoa controla os compartilhamentos autorizados.
- Registros ausentes não significam ações ausentes.
- Relatórios apoiam decisões, não as substituem.
