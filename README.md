# Guivos AI — Repositório Mestre de Conhecimento

**Versão documental 2.0 · 31/10/2026**

Este repositório é a **base mestra de conhecimento, análise, governança e evolução da Guivos AI**. É um projeto independente do [Guivos Knowledge Repository](https://github.com/guivos-repositorio/Guivos-Knowledge-Repository).

Não se destina a divulgar ou comercializar um produto, nem a oferecer interface pública de consulta. O endereço [GitHub Pages](https://guivos-repositorio.github.io/Guivos-AI/) existe exclusivamente para **leitura e acompanhamento da documentação**.

## Regras
1. Registrar evidências, hipóteses, limitações e decisões separadamente.
2. Uma proposta publicada não se torna automaticamente uma decisão aprovada.
3. Manter o repositório e seu índice no GitHub Pages sincronizados a cada avanço aprovado.
4. Não alterar o GKR por consequência automática de mudanças na Guivos AI.
5. Não publicar dados pessoais, segredos ou informações confidenciais.
