# Plataforma profissional e API — Guivos AI

## Mercado potencial
Mentores, coaches, orientadores de carreira, instituições educacionais e, mediante salvaguardas adicionais, profissionais de Psicologia e serviços de saúde.

## Dois canais
- **Plataforma profissional:** acesso a vínculos autorizados, histórico de análises e emissão de relatórios.
- **API:** camada de inteligência integrada a sistemas já utilizados por parceiros.

## Fluxo conceitual
1. Pessoa cadastrada na Guivos.
2. Solicitação de vínculo por profissional/parceiro.
3. Autorização específica e verificável pela Pessoa, respeitando requisitos aplicáveis.
4. Consulta às fontes permitidas e inclusão opcional de observações profissionais.
5. Análise de trajetória, contexto, lacunas e possibilidades.
6. Emissão do relatório e trilha de evidências apropriada.
7. Revisão, revogação e auditoria de acessos.

## API futura (não implementada)
Funções conceituais: verificar vínculo/escopos, solicitar análise, consultar status, recuperar relatório, revogar acessos. Definições de endpoints, autenticação, preços, limites e SLA estão pendentes.

## Modelo comercial
Assinaturas e/ou cobrança por relatórios/API são hipóteses para validação. Comercializa-se capacidade analítica, não dados pessoais.
